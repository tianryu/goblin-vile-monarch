最终提示词方案：

1. 以当前1280x600横屏实机图为精确编辑底图，保留平面哑光手绘贴纸、丑萌哥布林、米色描边、中世纪洞穴与部落、单独水面和陆地。删除原HUD、费用虚影、摇杆与操作键，仅加主菜单。左上清晰标题“我是哥布林：君主”，右下拇指区三个大号橄榄绿米金边按钮“继续游戏”“新的征程”“系统设置”，其他区域保留场景。禁止3D、像素、写实、高细节概念插画、手机外壳和额外说明字。
2. 同一实机底图并参考第一张菜单、既有羊皮纸底板与绿按钮，仅增加压暗背景后的系统菜单。温暖米色纸面、橄榄绿控件，大标题“系统设置”，五行音乐与音效滑杆、震动开关、流畅/标准选择、30/60选择。底部左“返回主菜单”、右“继续游戏”，按钮大而易点，不加重新开局、删档或广告功能，不放右上小关闭键，不用中点分隔符。

图中文字、主题风格和布局已经人工检查，具体触控尺寸、滑杆操作、显隐动画和性能尚未实现验收。全局渐入渐出继续适用。本轮未切换整套美术风格。
