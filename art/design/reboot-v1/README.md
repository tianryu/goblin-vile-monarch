## 已发现并处理的问题

1. 初版村落囚笼误关绿色哥布林，已经改为人类联军。己方监牢收押联军，敌营牢笼才关被救同族。
2. 底部触控太贴边，整体上移，保留安全余量；水面承载控件，避免遮住游戏道路。
3. 用户认为初版人物太友善，改大尖耳、歪鼻、小獠牙、眯眼坏笑和紧凑驼背轮廓。
4. 首次丑萌修订产生细线插画脸，另外生成粗像素修正版，保留丑萌形态并减少微观细节。
5. 夜防图弓手曾出现类似王冠的头饰，改成普通头带；只有首领戴王冠。
6. 夜防交互标签原先离首领太远，改指向左侧低路障；捕网底部落在路面。
7. 用户要求去掉中点分隔符；源文案已清理，最终夜防标签单独修正为四字连续“路障修复”。

## 每张检查项目

- 与同组图保持低像素世界比例、蓝绿森林、暖色火光及清楚的地面。
- 丑萌哥布林与人类、精灵、矮人可区别，职业工具可读，普通肚子与鼓口袋可区别。
- 人类剑盾分属两只手；矮人锤、精灵弓的握持合理，拖网和推轮没有多余肢体。
- 监牢人数和容量可辨；盗贼赃物与缺轮车轴对应。
- 左侧水平摇杆，右侧奔跑/当前交互，安全区与中文可读，无全局外挂按钮和世界点击提示。
- 所有可见文案无中点分隔符。文本扫描只验证源文件，图片中的字形需人工看图。
