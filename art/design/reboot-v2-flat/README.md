# 平面手绘画风方向稿

日期：2026年10月30日。用户已认可本轮平面手绘画风，当前修正同一张监牢交易图的服饰、关押与拖运细节，不扩展生产素材。玩法与操作见../../../docs/GAME_DESIGN.md。

## 用户反馈

上一轮整体3D感、建模感偏重。要求更平面、手绘感更强、细节不用分得很清、色彩不必强烈分离。人类商人不穿风衣。

最新反馈：画风可以，但世界是中世纪，商人不能穿现代夹克戴宽帽；被关押者全身应在笼子里面；一个哥布林拖运即可。此反馈覆盖初稿软帽、短马甲与两人拖运要求。

## 本轮目标

- 小角色、低原生像素与横版单地面继续保留。
- 手画般略不规整的大色块，材质以两档接近明度为主，少亮边、反光、硬黑描边和体积塑造。
- 森林由成片形状表现；地面减少逐块石纹；木头、铁栏和轮子减少雕刻般的细节。
- 灰蓝、灰绿、土褐、褪红与少量暖色统一画面，文字与关键轮廓仍可辨。
- 哥布林继续大尖耳、歪鼻、小獠牙、坏笑的丑萌方向。
- 人类商人露出短发和胡须，不戴帽，穿粗麻套头短袍、束腰带、布裤、绑腿与旧皮鞋。没有夹克、马甲、现代衬衣领口或宽檐帽，两手分别拿钱袋和账本。
- 俘虏全身缩进铁笼内，前排铁栏位于人物前方并遮住部分轮廓，头手脚不伸出边界。
- 只保留一名哥布林在左前方牵绳，网兜和人类俘虏拖在右后方，朝监牢方向走；水面也不能残留第二名搬运者。
- 中文与布局保持：38金币、24人口、第6日、4/6监牢、人类商人、交易、奔跑、水平摇杆、安全区。无中点分隔符。
