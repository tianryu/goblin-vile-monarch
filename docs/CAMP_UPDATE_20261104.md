# 洞口与俘虏商人试玩更新

本批构建标识为 `camp-update-20261104`，固定目录为 `release/cocos-camp-update-20261104-r1`。已接替 [42828 试玩入口](http://127.0.0.1:42828/?build=camp-update-20261104)，原构建目录保留。第一章的完整对白和引导见 [第一章实施清单](CHAPTER_ONE_IMPLEMENTED_20261104.md)。

- 旧档保留金币、建筑等级和战役进度。尚未开始的旧档补开场，已开打的旧档从当前进度继续，完整开场可选「新的征程」。
- 洞内主厅、钱箱、牢笼、缴获装备堆和装备台左移。装备堆与牢笼相距 355 个世界单位，商人移到洞外独立停靠。洞口赠送一座一级箭塔，教学仍引导建设外侧箭塔。
- 俘虏商人一人拉一辆独立绘制的笼车。按车厢可用空间展示最多三名已交易的俘虏，交易数量仍按实际入账。商人离开前走到车的另一侧，载货离场。旧的板车和固定监牢叠画已从此处移除。
- 装备拆卖成功时复用金币音效。奔跑按钮按下后带金环和状态文字，耗尽时显示体力恢复。首领生命不高于 30 时，红色屏幕边缘随呼吸渐变，受击时另有短闪。
- 角色数下方竖排金币援助、部落援军和更换坐骑。旧世界广告摊位已移除。锁定坐骑由真实激励广告解锁，已解锁坐骑可直接切换。当前本地广告服务未启用。
- 人类剑兵、矮人锤兵、精灵弓手和短刃兵复用已接受的原动作姿势，共享一张 900×576 图集。盾兵、法师及其他精锐使用贴纸式蓄势、出手、收势和已有特效。攻击伤害与投射物在出手时结算，离开有效距离可以避开蓄势攻击。

验证范围为 TypeScript、Creator 构建、导入资源和本地 HTTP 版本核对。按用户要求由用户试玩，本轮未做玩法、浏览器画面、实体手机和性能测试。此包用于本地试玩。
