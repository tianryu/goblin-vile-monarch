# V7场景内交互与昼夜重做

本轮已完成本地实现与模型、浏览器、Web导出验收，用户2026年10月31日最新要求替代V6的资源、弹窗、袭击时段及地图规范。手机真机与TapTap宿主仍未验证。当前证据以qa/godot/v7-acceptance.json为准。

- 手机横屏不变。先完善玩法与表现，本轮暂停旧24MiB和包体硬门槛，仍记录实际资源与运行数据。
- 除死亡与通关结算外无对话框，无开始页、商店、暂停菜单、教学、任务说明、目标名称或操作文字。暂停是右上图标原位切换，旋屏仅图形提示。世界只靠近后按底部图标，不直接点击世界。
- 工具摊没有卖家。每种职业一摊，逐枚投入金币，购买完成后挂出真实库存工具，空闲爪牙走过去取走。商人、坐骑、出征和盗窃选择放在不同的场景标志点，图标加价格牌表达，无解释文案。广告仍自愿、无限、无冷却，无SDK不伪造奖励。
- 唯一货币金币。取消废铁，拆解、装备搜刮、盗窃均获得金币或原来的具体战术效果。携带上限50；多余金币进主厅金库，建设只从钱袋逐枚投入，玩家到主厅取钱。金库堆宽高随金额增长。正常收入由哥布林带回金库，私藏仍独立记账。旧存档废铁按一比一转换为金库金币，广告来源的未花余额继续保留。
- 鞭子可对任意活哥布林使用，有藏钱时把真实金币打落，没有时提升移动和工作。效率久未受鞭会从100%降到最低80%；加速有时限，连续鞭打可昏迷，昏迷不工作，恢复后继续。以动作姿态、掉币和小星光表达，不展示私藏字样。
- 240秒一日，太阳0到120完整升起、过顶、落下，月亮120到240完整升起落下，天体放大。正午60秒联军发起进攻，夜里不再生成定时进攻。驻军和巡视者全天侦测最近的目标，先接近并攻击最近敌对单位，再进攻营地，不无视玩家。
- 世界边界左右9200，联军主营约左右8000，与主厅留出林地、河桥、遗迹和前哨纵深。前线集结在领地外，正午推进，既能看见白天进攻，也不把主营挤在玩家家旁。
- 不等距排布。加入不同树种、疏密林地、草丛、鸟蝶、浅溪桥、蘑菇田、伐木营和金币矿。生产建筑真实工作出金币。主厅一级只开放锤弓和内防线，二级开放打手、监牢、商人和中线生产，三级开放盗贼、矿场、远防线。未开放的建造点、牌子和虚影完全隐藏；领地边界实际外推，探索移动不设空气墙。
- 绘制次序为建筑及后方装饰、首领、其他哥布林和敌人，水与岸边前景在最后。囚笼内部仍保持后框、囚犯、前栏杆。
- 活口先倒地挣扎，死亡倒地静止，都不自动变成网兜。只有工匠收拢拖运或真正的网陷阱才出现网。静态姿势配小幅变换，本轮不生成角色帧动画。
- 靠近目标有程序化呼吸微光，地上金币也有呼吸光。夜间使用蓝色环境光、月光、局部暖火、萤火、星点、水面冷光；日间有日光方向、林隙光、鸟蝶和晨雾。法线由原AI位图低频亮度和轮廓烘焙为同坐标技术贴图，用于CanvasTexture，不程序代画角色或建筑。
- 新美术仍为独立AI静态位图，非像素、平面手绘、哑光低对比。每张检查后入库。角色帧动画继续延期，不操作任何TapTap应用。

验收分组：金币与迁移对账；50容量和手动取钱；各摊直投与工具领取；所有功能无弹窗；鞭打掉币/加速/昏迷/效率下限；主厅三级解锁和地图层次；正午唯一波次与全天最近目标AI；活口/尸体/拖运区分；完整日月轨迹与夜间局部光；手机触控、旧存档、胜败重开与正式Web启动。旧测试中绑定夜袭、废铁和商店面板的断言改为历史，不能宣称它们验证本轮。

## 实现与验收记录

30张新增AI静态位图均逐张检查，原图、完整提示和选用检查记录位于game/art/source/world-v7。四个空摊、职业高位标志、六种负伤/死亡姿势、树种、河桥、生产、钱袋、天象盘和图标已经入生产图集。己方旗改为黑布红色哥布林标志，损毁攻城车用落地残骸。角色没有制作帧动画。

当前149项场景断言分为模型43、复杂玩法36、原生UI8、浏览器交互30、坐骑/广告适配器/多指11、正式包11、启动音频10。另有三个无广告、无资源注入的加速模型征程完成双旗：种子731与55第6日，123第7日。复杂玩法检查包括四种偷窃现场作业/返回/下一波效果、俘虏容量预留/售出囚车/一次性金币、陷阱捕获与工匠重装、保留守军、低飞受箭和永久奖励跨局保留。受控广告回调不代表真实SDK。

复查修正了工具摊附近鞭打与取钱冲突、精灵射程内工匠错误工作、升级领地后波次抵达过晚、旧存档已付设施被隐藏、已拥有坐骑重复广告强化缺失，以及盗贼把军饷直接塞进首领钱袋。附近哥布林有独立的条件鞭子图标；所有付币动作统一金币图标，任务与商品区别放在场景标志牌，切换坐骑显示该坐骑。

法线来自原AI漫反射与alpha的低频技术烘焙，严格对齐原图集。默认world_light_fast.gdshader读取CanvasTexture的NORMAL，用统一轻量计算合成日月方向光和最多8盏火炬灯，透明像素先跳过，保留原生DPR和纹理清晰度。DirectionalLight2D与PointLight2D节点负责光源参数，原先通用引擎light()着色路径保留作诊断对照。实现依据[Godot CanvasItem着色器文档](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/canvas_item_shader.html)，不是程序代画美术。

300秒桌面Edge软件WebGL、DPR2，18名己方、20名高耐久敌人及后续波次，完成自然昼夜循环并保持存活，没有脚本/着色器错误。rAF帧间隔P50 30.3ms、P95 48.5ms、P99 48.6ms。优化前P95 139.3ms的原报告保留；当前仍未达到40ms内部软件压力目标，不能写成低端手机性能通过。纹理单份RGBA约55.02MiB，含启动与开场图约57.61MiB，不等于进程总内存。包体预算按用户要求暂停。
