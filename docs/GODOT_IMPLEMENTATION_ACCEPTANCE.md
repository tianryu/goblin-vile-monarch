## 证据和实际限制

qa/godot/model-tests.json是43项原Godot模型回归；finishing-model-tests.json为35项整改场景；campaign-bot.json为三条无广告、无资源注入的完整逻辑征程；browser-tests.json为18项桌面触控模拟；finishing-browser-tests.json为69项多尺寸界面、交互、广告异常、存档备份和结算检查。广告使用明确受控接口，不能称为真实SDK成功。stress-browser.json为桌面软件WebGL五分钟片段；release-smoke.json单独检查正式导出及无调试入口；release-package.json保存包体和SHA256。整改前压力报告保留为stress-browser-before-polish.json。

当前是可本地试玩的Godot静态贴图版本，不能宣称所有最初约束已全部验收。未完成项为真实手机/TapTap宿主、真实广告接入、用户更换风格后的新版同视角90%视觉对照，以及进一步的人工长程平衡调校。没有用历史像素设计、同一张实机图或旧原型测试冒充通过。12小时是用户约束，不作为完成证明。
