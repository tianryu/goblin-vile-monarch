结论：在本桌面短测条件下，逻辑开销较低，没有出现脚本阻塞；常驻纹理119至136 MiB仍是我判断的优先风险。ArtBank启动会加载静态素材目录，视野裁剪减少画面工作，不自动减少纹理常驻。加载并发限制只控制启动请求峰值，也不降低最终常驻量。下一步应先核对哪些纹理正在被图集和字体重复驻留，再做按区域/用途载入与可回收缓存；不通过删玩法或隐藏未处理问题宣称达标。

本批只评估，没有为此进行未经对比验证的性能重构。需要目标安卓设备上实际采集GPU纹理、进程峰值、持续帧率和温升，再决定流畅档的取舍；不能把SwiftShader的26至30帧外推为手机帧率。证据qa/cocos/current-performance-20261103.json和performance-*.png，工具cocos/tools/current-performance.cjs。
