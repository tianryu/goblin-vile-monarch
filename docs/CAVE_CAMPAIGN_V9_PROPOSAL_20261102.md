# 单向洞穴战役与成长系统讨论方案

日期：2026年11月2日。状态：讨论稿，尚未实施。

本轮用户要求讨论昨天14项反馈，另提出6项整体玩法调整，随后补充建筑升级问题。第二轮纠正主厅与装备的属性关系，要求未筑墙敌区重建、删除偷窃、改造台三级自动更新已穿装备、临时俘虏放牢旁，并重设旗帜出征。统一跟踪见[问题台账](ISSUE_TRACKER_V9.md)，当前共25项。用户明确要求优先于本文建议，未确定的数值、名称及新增细节不是已批准定稿。现有代码和发行包仍为此前双向版本；本轮只更新文档，不生成素材、不改玩法、不导出或操作TapTap。

## 1. 总体判断

建议采用单向洞穴战役。它让洞穴生活、向右扩张、战后搜刮、俘虏交易、改造猎手和缴械反攻形成连续循环。每天防守也能积累夺取下一个据点的力量。

需要同时控制三个风险：洞穴不能成为敌人永远无法进入的无敌区；夜袭不能无上限积累成为迟早必败；装备和缴获不能从同一目标反复结算。玩法深度优先来自兵种、设施和战利品的组合，不堆复杂背包或额外货币。

## 2. 单向地图和洞穴生活

用户方向：最左侧是哥布林洞穴，主厅与居民在洞里，从洞外开始建设，向右逐层攻到运兵船。

建议路线：洞内生活区、洞口工作区、初始林地与防线、斥候营地、先锋营地、前军营地、中军大营、登陆码头与运兵船。各敌营之间保留可建设的安全地、林地、动物和生产点，避免五个营地首尾挤成五扇门。

- 洞穴以横向剖面表现，仍在同一移动平面上连续行走。进入洞穴不弹窗口，不切成第二张经营地图。
- 洞内安置主厅、金币箱、开局小笼子和战利品堆；满牢或暂不能入笼的俘虏就绑在监牢旁边的地面，不另建临时拘押建筑。生活区在背景里表现，不让每个装饰都占交互位。
- 洞口外先放易辨的职业摊与招募设施，随后才是第一道防线。核心设施紧凑，前线与敌营拉开，分别解决“家里跑得累”与“敌营离家太近”。
- 紧凑不等于所有功能挤在一屏：主厅、钱箱和小笼互相可见，工具与交易分布在相邻镜头；相邻交互点仍需有足够距离，避免当前目标抖动。
- 三位广告商人在内营或洞口的相邻位置保留，各自独立形象；现有自愿、无限、无观看冷却的规则不变，不用广告门槛阻断战役。
- 初期建设位就在洞口附近，向外分段解锁。主厅升级开放能力，夺取据点获得前线空间，仍需修建防御，不能一升级就凭空拥有整片领土。
- 洞口防线被突破后，敌人能进入洞穴，先攻击附近敌对单位，再威胁首领。主厅毁坏仍不是直接失败，首领死亡才判负；洞穴不是无敌避难所。
- 旧的双向指挥营、左右运旗胜利与正午定时袭击由本次新方向替代。旧档如何处理另议，不能静默删掉用户进度。

## 3. 五层战役的差异

| 阶段 | 敌方特征 | 玩家面对的新选择 | 占领收益建议 |
| --- | --- | --- | --- |
| 斥候营地 | 轻步兵、小队侦察、少量射手 | 最初的路障、猎手和战后捕俘 | 第一段前线安全区与林地生产点 |
| 先锋营地 | 人类步兵与精灵游侠混编 | 近战护卫、箭台和混编出征 | 更多建设空间与稳定的装备来源 |
| 前军营地 | 大盾兵掩护，投石车或冲车入场 | 单靠猎手不够，要恶霸、陷阱或缴获器械配合 | 修械场能力与较完整的敌方军需 |
| 中军大营 | 矮人重兵、火焰投石车、少量魔法大师 | 抢先拆后排、避开火区、保护工匠 | 通向港口的道路与高阶改造能力 |
| 运兵大船 | 码头守军、精锐盾兵、法师与有限登陆增援 | 保护器械推进，打破码头和登船防线 | 沿跳板占领船上指挥点，触发胜利 |

船作为横版终点堡垒：码头、跳板、甲板在同一方向连续推进，先不增加航海操船或海战。击败前一个营地不会自动消灭地图上仍在交战的敌军。打下但未在对应区域筑墙的敌营会再次出现，见第12节；不能把清空敌人直接当成永久占领。

## 4. 傍晚夜袭与伤亡撤退

用户方向：每天傍晚军营派兵夜袭，随时间增强，天亮不撤，倒地达到一定数量才撤退。

建议规则：

1. 袭击从最近的未占领敌营出发，更远营地提供阶段性兵种和补给，不在已占区背后凭空刷兵。
2. 出征前确定本支部队编制和伤亡门槛。普通队伍可先用约40%至50%失去战斗能力作为调试起点；精锐更顽强。具体比例必须后续游玩调校。
3. 阵亡、负伤倒地和已被俘都计入失去战斗能力，同一敌人只算一次。短暂被网绊住后仍能恢复战斗的不立即按阵亡计数。
4. 达到门槛后本队幸存者向右撤退，放弃器械；猎手可以追射。已经撤回者本夜不立即重新编队冲锋。
5. 天亮只是环境和生产时段改变，没有撤退指令。未达到门槛的旧队继续交战；后续补兵并入有限编制或排队，不每日叠出无限个独立满编军团。
6. 天数提高基础压力，但各战役阶段有可调的规模上限。占营会削弱其补给、改变出兵起点，让主动推进能改善处境。首夜要给四爪牙开局完成工具和第一道防线的时间。
7. 撤退用逃跑姿态、散队和落旗表现，不能整队淡出消失。驻营守军与野战部队分开，不因为一队撤退就让整座营地瞬间清空。

“兵越来越多”体现为兵种、编队和有限增援增强，而不是必须不断增加同屏实体。离镜战斗遵循同样规则，后台和广告暂停不补算战斗。

## 5. 丰富兵种，保留可读的克制关系

| 兵种 | 行为与识别 | 克制与弱点建议 |
| --- | --- | --- |
| 人类轻步兵 | 快速接近、近战冲锋 | 受路障和集中箭火克制 |
| 精灵游侠 | 远程压制，拉开距离；空箭袋形象保留 | 被恶霸近身后明显变弱；箭袋按实际射击耗尽，不再依赖偷窃 |
| 矮人破障兵 | 较慢但打墙重，重装备轮廓 | 集火、落石与器械打击；不能所有攻击都免伤 |
| 人类大盾兵 | 中期出现，正面大盾掩护后排 | 正面减免大部分箭伤；近战攻击、落石与投石可破阵 |
| 魔法大师 | 后期少量出场，明显施法姿态 | 被近身容易打断，优先处理其护卫与站位 |

大盾不建议完全永久免疫箭矢，否则尚未缴获器械或失去恶霸时容易卡住。盾兵攻击或踉跄时暴露弱点，不在单一路线上强加必须绕到背后的操作。

法师普通技能为可见飞行火球；火雨为少量间隔较长的落点攻击，有明确预警，落点确定后不持续追踪首领。己方单位会短程避开火区。普通墙不完全免疫法术，但法师不能隔着整张地图直击洞内首领。战场上避免大量法师同时叠火雨。

## 6. 三类攻城器械与缴获反攻

| 器械 | 入场阶段建议 | 敌方作用 | 缴获后的价值与限制 |
| --- | --- | --- | --- |
| 破门冲车 | 前军阶段 | 近距离重击路障或营门 | 出征拆营门，移动慢，需要近距离保护 |
| 投石车 | 前军阶段 | 抛物线打击防御与聚集单位 | 对营地和盾阵有效，装填慢，有明显弹着点 |
| 火焰投石车 | 中军阶段 | 火罐落地形成短时火区，逼迫离开阵地 | 能压制敌营；炮火会伤己方，不能贴着前排盲射 |

重弩车可作为后续候选，不先把第四套机械加入首批必做内容。器械要有最小射程或开火距离，不能贴墙零距离连续砸穿一切。

最新流程：敌人撤退、弃械、附近安全、哥布林推回当前防线后、修复、玩家在器械处付币征召两名工匠、推到洞口出征旗集结、玩家在旗帜处付币发令、全队自动向目标营地推进。取代上一稿的跟随首领出征。

- 每台器械是同一个有ID的实体，所有权改变，不在缴获时另外复制一台。摧毁的残骸只能回收金币，不能自动恢复成完整器械。
- 缴获后优先停在当前有效墙后。正式征召加入出征时，每台器械固定配两名工匠，先推到洞口旗帜集结；这两名工匠占两个军队名额，器械不额外占人头。不改变俘虏单人拖运的要求。
- 建议从部落已有工匠中征召，不免费生成劳力；缺两名可用工匠、旗帜不足两个空位或器械未修好时不扣费，也不先征走半组。该具体征用规则待确认。
- 在器械处付的是征召操作工匠的费用，在旗帜处付的是本次出征费用，功能分开；未投满离开仍按原规则退还。回撤建议免费，用旗帜处图标发令，不弹器械管理窗口。
- 行军时不穿过未摧毁的敌方营门；部署后停稳再攻击，防止镜头外跨营射击。操作员受威胁可逃离，器械留在现场。
- 石块或火罐由装填节奏与金币维修表达，不增加独立的弹药货币。偷车轮等偷窃任务全部取消。

## 7. 主厅基础属性、装备百分比与扒装备

用户方向：阵亡和被俘的敌人倒地后都被扒走装备，运到洞内，玩家花金币改造成猎手装备，提高攻击、防御和生命。

用户已纠正：主厅等级提高职业基础属性，装备单独提供百分比增幅。两个维度同时生效，不能取消主厅的属性提升。装备改造台共3级，最高等级受主厅对应等级限制；制造装备较贵，改造台升级完成后，所有已穿上一级装备的单位统一更新为新一级装备。

按职业、主厅等级计算基础攻击、防御、最大生命，再应用装备各项百分比：最终属性 = 当前基础属性 ×（1 + 当前装备增幅）。未穿装备的单位增幅为0。装备等级更新是替换旧增幅，不是把每次升级的百分比再叠一遍。

仅作算式示例：基础攻击10、一级装备增幅20%时为12；主厅升后基础攻击变14，同一装备下为16.8；改造台二级若增幅40%，已穿装备的单位自动变为19.6。10、14和20%、40%均为说明数字，不是已定数值。

制造循环为：安全战场搜刮、运回洞内杂装堆、到改造台逐枚投金币、工匠消耗库存制作、成品摆上台、未装备且符合职业条件的单位领取。每件新装备只增加一名穿戴者。改造台升级则更新已有穿戴者，不给没穿装备的人凭空发一套。

- 初始普通猎手通过弓摊获得，仍能狩猎、防守与打斥候营，不能先要求有战利品才能获得第一名有战斗力的单位。
- 主厅1、2、3级分别允许改造台最高1、2、3级，改造台需要另行投币建造与升级，不能主厅一升级它就免费一起升级。
- 改造台每级制作对应装备，所有已穿旧级装备的单位在该建筑升级完成后统一更新，包括已集结、出征或返程的单位；装备数量与归属不增加。未穿戴库存是否同步换级尚待讨论，不能冒充用户已指定。
- 制造价格应明显高于基础职业工具价格，改造台升级价格也需体现批量更新装备的收益；每级具体费用和增幅尚未确定。
- 视觉上保持红色猎手服、弓箭和独特轮廓，用更多防具体现装备变化；角色主厅成长与装备变化可以组合，但不能一切动作切回旧服色。
- 当前装备方案先明确覆盖猎手，建议同时让恶霸有对应的近战装备；是否覆盖其他职业待确认。偷窃取消后不再设计盗贼装备。
- 每个敌人只产出一次装备。倒地、被俘、逃跑、再击倒、再出售都不重新生成；剥装后用里衣和失去武器的形象识别，无需裸体或复杂换装背包。
- 己方已装备单位阵亡可讨论回收已有套装，只转移原物，不凭空增加一份。是否全额回收及维修损耗待讨论。主厅或装备属性变化不得无故复活死者、重复回血或重新发奖。
- 战利品堆按库存区间换装饰密度，保留可核实数量；大额库存不无限生成每一件小图片。装备不能强制挤占金币箱或俘虏位置。
- 多余杂装可讨论拆售为少量金币，与制造消耗互斥。敌人同时提供随身钱、装备和俘虏时，要压低零散金币，避免三份高额收益把普通经济冲垮；出售俘虏也不能再次附送同一份已经剥走的装备。

## 8. 建筑成长必须覆盖生产与后勤

静态核对当前model.gd的upgrade_info：主厅、路障、监牢各3级；箭台、吊网、落石架各2级；旧盗贼窝、蘑菇田、伐木营、金矿仅1级；工具摊是付币增加工具库存，没有独立升级线。当前主厅升级还直接promote_unit全部职业。主厅的职业基础属性成长保留并补齐，装备另加百分比，生产后勤补齐升级。旧盗贼窝属于待移除功能，不进入新成长表。

建议下表作为新版本的成长骨架。不是每个装饰、商人都强行设置三级；升级必须带来玩家能看见的功能变化。

| 建筑 | 建议等级与外观变化 | 功能成长 |
| --- | --- | --- |
| 洞内主厅 | 3级，破烂议事台、赃物大厅、部落王座厅 | 职业基础属性、人口容量、建筑与技术解锁；与装备百分比同时生效 |
| 洞口营门 | 3级，简栅、木闸、加固铁闸 | 更强的最后防线，后期增加耐火能力，但仍可被攻破 |
| 前线路障 | 3级，矮木障、尖桩墙、拼装铁板墙 | 耐久与防御提高，成为生产单位的安全退守线 |
| 箭台 | 建议3级，单人台、双人台、带遮棚箭楼 | 驻守人数或射界成长，后期对抛射提供有限保护 |
| 吊网与落石架 | 各2级，轻架、加固重架 | 控制重兵或群体伤害成长，装填仍需工匠 |
| 监牢 | 3级，小木笼、铁笼、洞内牢房 | 容量、守备与较低逃跑风险；满牢仍可临时拘押 |
| 招募吸引建筑 | 建议3级，摆钱破牌、招募火盆、破旗聚落入口 | 可预放金币与等待位置增加，到访更稳定；不指数加速人口增长 |
| 各职业工具摊 | 通常2级，简桌、完整专用工作台 | 更合理的库存陈列与更好工具能力；每职业独立，猎手战力不由弓摊自动集体升级 |
| 装备改造台 | 3级，分别对应主厅1、2、3级 | 制作较昂贵的百分比增幅装备；本建筑升级时自动更新已有穿戴者 |
| 洞口出征旗 | 主厅2级解锁建造，旗帜自身可升级 | 队伍名额、集结与出征；等级数量和具体容量待确认 |
| 蘑菇田 | 建议3级，散生菌床、整齐菌架、洞外菌棚 | 每名工匠的产出效率和稳定性成长，不凭空增加免费劳力 |
| 伐木营 | 建议2至3级，劈木处、锯木台、加固木场 | 清理效率、金币产出和可施工空间成长，不添加木材货币 |
| 金矿 | 建议3级，浅采、矿架、深井入口 | 每名工匠的产出与运送效率成长，需要保护较远的矿区 |
| 修械场 | 2级，露天修理架、加固器械棚 | 修复基础器械，再支持重型或火焰器械；不能凭空量产未缴获的器械 |
| 钱箱、三商人、交易停靠处 | 不独立强制升级；钱箱可随主厅换外观 | 核心功能持续可用，不用付费扩箱卡住金币，不把广告权益做成科技门槛 |

主厅既提高职业基础属性又提供解锁条件，营地进度提供可用空间；工匠施工、实际金币投入与设备库存决定建筑成长是否完成。主厅升级不等于自动升满全部建筑，装备改造台升级则按用户要求统一更新已有穿戴者。前线防御允许毁坏后重建，永久技术解锁不因丢一面墙清零。

每级要同时检查外观、功能、费用、工时、工匠位置、损坏与维修、存档。升级主要通过材质、配件和清晰轮廓区分，不能每级简单放大，重新出现建筑粗大遮挡。所有出现、消失和状态替换延续全局渐入渐出。

## 10. 待讨论的数值与边界

1. 洞穴可攻入，首领仍会被击杀；主厅毁坏不是直接失败。
2. 装备是百分比增幅，主厅提升基础属性；制造逐人领取，改造台升级统一更新已有装备。具体百分比、价格和未穿库存的处理待定。
3. 前线空间依赖清营与对应城墙，旗帜等级和名额待定；不把主厅基础属性成长与装备更新当成同一次重复加成。
4. 夜袭按独立编队伤亡撤退，天亮不撤；每天增强有阶段上限，占营能削弱后续压力。
5. 临时俘虏放监牢旁已确定；上限、逃跑机制与能否直接出售待讨论。每台出征器械两名工匠、占两个军队名额已确定，征用和缺员处理见下一节建议。

## 11. 恶霸与洞口旗帜出征

当前实现核查：除猎手还有恶霸brute，基础生命36，猎手18，近战命中伤害13；旧出征也会选恶霸。因此并非没有近战单位，但缺少明确的承伤、防护和队形表现。建议沿用并强化恶霸，形成大盾配短斧或粗棍的厚血前排，不再新增一个职责重复的近战职业。其具体造型、生命与减伤数值仍待确认。

用户明确的出征流程：

1. 主厅2级后可在洞口建出征旗帜。
2. 靠近猎手时，保留鞭打按钮，增加征召图标按钮；征召后猎手停止日常狩猎或守备，主动到旗帜集结。
3. 靠近器械付金币，为该器械征召两名工匠，推着器械去同一旗帜集结。
4. 玩家在旗帜处投满本次出征金币，集结部队自动出征，无须跟随首领。
5. 没有器械的队伍小跑推进；有器械时按推车速度护送前进。接近敌人或营门自动交战。
6. 集结队伍人数受旗帜等级限制。一个猎手一名；每台器械与两名工匠合计两名，器械本体不另占人头。

建议补充，尚待确认：

- 恶霸也有同样的征召/取消征召按钮，占一名额，前排拦敌、猎手居后射击、工匠在保护下操作。保留纯猎手队可以出征，不沿用旧代码“必须一名恶霸”的硬门槛。
- 旗帜可以先采用两级：主厅2级允许一级旗，建议容量8；主厅3级允许二级旗，建议容量12。这是初调建议，不是用户已指定的容量。
- 例：容量8时，2恶霸、4猎手、1台器械及其2工匠正好占8名。性能统计仍包含器械实体，不能把队伍计数当渲染实体数。
- 征召立即预约名额，在路上的单位也占名额。器械必须一次预留两名工匠和两个名额，剩1格时不接受半台器械，也不扣钱。
- 推荐从已有且可调动的工匠中征用，不打断紧急抢修或搬俘；如果用户希望付币额外雇来两人，需要另外确认人口来源和人口上限规则。
- 鞭打与征召分属不同图标，集结前可取消征召；受击不误取消部队。旗帜旁显示人数或队列占位，仍不使用管理弹窗。
- 同旗先管理一支队伍，包含集结、出征和返程者；是否允许多支独立队伍后续讨论，避免把旗帜驻留名额直接变成无限叠队入口。
- 默认只攻最近的未巩固敌营，攻下后短距离驻守等待玩家筑墙或下令返程，不擅自一路穿过全部营地。
- 护械队接敌时前排短距离拦截，猎手到射程停下，清敌后归队；不能为了追单个残兵把整台器械和工匠甩在后方。
- 负责器械的工匠有护卫且敌人尚远时继续操作，敌军突破近身才弃械逃跑，避免“刚看见敌人就弃车”。缺操作员时器械实际停下，不能自行滑行。
- 建议保留旗帜处免费回撤命令；出征费用、器械征召费用和投币未满退款分别结算，重复点击或显隐动画不重复收费。

## 12. 筑墙巩固与敌营重建

用户已明确：所有区域清掉敌营后，如果未在对应区域建城墙，敌营会再次出现。各区域需要独立记录清空、筑墙施工、已巩固、城墙失守与敌营复建状态，不能靠主厅升级或远处任意一面墙永久占全图。

建议留出巩固窗口，城墙必须建成且有效才能结束本区复建风险；只投第一枚金币或只出现建筑虚影不算筑墙成功。未筑墙时给营地残旗、返场动静或复建进度等场景预告，敌方逐步重新搭营，不在玩家镜头转开后瞬间刷满军队。时间、返场来源及墙毁后多久重新计时待讨论。

已有巩固城墙被摧毁后，建议重新进入失守阶段，而非立刻抹掉所有生产建筑；仍有驻军和其他有效防御时的具体区域归属规则待定。敌营重建不会重复发放首次占领奖励和永久解锁，同一装备/俘虏仍遵循单次归属；新敌兵可有正常战利品。

最后码头与船区也纳入这条领土规则。建议先巩固登陆区对应城墙，再夺取船上指挥点完成胜利，避免占船即结束与未筑墙会复建产生矛盾；这是结算顺序建议，待用户确认。

## 13. 取消偷窃

用户已明确删除偷窃玩法。新设计不再保留盗贼职业、盗贼工具摊、盗贼窝、偷箭袋/偷车轮/偷军饷/偷钥匙任务及其派遣、计时、弱化敌军和补充人口效果。侦察与主动进攻仍可存在，不换名恢复自动偷钱任务。

当前代码与资源还保留旧偷窃功能，文档取消不等于已从游戏移除。后续实际修改需处理旧存档里的盗贼、工具库存、已付款任务和在途物资，建议返还未结算成本并保留人口与已到账金币，具体迁移方案另验收。旧原素材只归档，不在本轮删除。

以上均有明确讨论方案，但没有实现或新增验收证据。下一步仍是用户讨论方案，不自动开始美术或开发。
