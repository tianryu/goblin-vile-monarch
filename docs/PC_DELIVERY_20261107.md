## 已实现

- Windows x64 原生入口，1280x720 初始客户区，使用游戏图标，随包加载手绘字体。
- A/D、方向键、Shift、E、Q、R、Tab、H、M、Esc、Enter 和小键盘 Enter 的操作绑定。固定 E/Q 图标，底部桌面操作栏，失焦释放输入，关闭窗口保存。

- 中英文艺术字、五段剧情、引导、建筑作用、动态资源、结算、鸣谢的显示翻译。保留原玩法、兵种、建筑成长和第一章战役。
- PC 移除广告入口和未接通的平台功能，坐骑一次性金币解锁。既有手机代码、旧包和旧存档保留在 main 与本地输出。
- Windows 构建脚本、桌面预览模板、便携打包脚本及 DLL 依赖检查。

## 构建中发现并处理

1. 桌面默认模板使用4:3固定画布并带页眉页脚，已改为填充窗口。
2. 底部按键说明被裁掉，已整体上移；英文剧情标题、结算文本限定宽度，长对白先译后按词换行。
3. Creator 命令行成功退出码为36，构建脚本同时核对完成标志，不能按普通0退出误判。[官方命令行说明](https://docs.cocos.com/creator/3.8/manual/en/editor/publish/publish-in-command-line.html)
4. CMake 的 VS 后置 DLL 复制在中文目录失败，改为先通过 PowerShell Unicode 路径预置同版依赖，再正常编译，不跳过编译错误。
5. Windows 以导出 UUID 文件名当作字体字族，导致回退系统字体。启动器按宽字符路径私有注册随包字体，显示层按真实字族使用，不安装系统字体。
