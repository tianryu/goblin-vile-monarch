# 五营守备、外征阵容与防御设施规划

2026年11月3日。用户已接受核心守备与外征预备队的分工，要求逐营规划兵种，并补充斥候营、先锋营可以仅有士兵与帐篷，后续营地需要围墙和箭塔。此轮只完成设计与编制核算，不改42826固定包、不生成美术、不运行战役测试。

基础编制数据保存在data/camp-army-rosters-proposal.json，精锐和Boss包含在人头数内，器械另算；数字是首轮提案，不是当前代码的驻军事实。沿用现有普通兵、六类精锐和三类Boss，不新增职业或玩家养成系统。

## 统一规则

- 核心守备初始15/30/50/70/30，末两营合计100；外征预备兵12/20/30/40/20。夜袭不得调核心守备，驻营精锐/Boss固定留守。预备兵在本营遭进攻时可增援，已在外征或运输的个体不瞬移回营。
- 以下核心编制包含全部塔上射手，箭塔不能在守军人数之外免费射箭。前军两名、中军三名、船四名精灵射手从各自核心编制中抽到塔位；他们阵亡后，空塔停止射击，真实守军补位后才恢复。塔毁幸存者落地，不复制士兵或刷新其生命。
- 营地主体一直是帐篷群，防线布在营帐外围。斥候、先锋不建围墙、营门、箭塔或其他固定攻击设施；前军起逐步发展木构、砖石与铁件。
- 两类兵源共用ID账本，核心伤亡、外征伤亡、补员分别记，不重复扣兵、不重新发同一驻营Boss。固定精锐人数不随普通驻军扩容而机械翻倍。
- 日常袭击人数按既定全局公式，第1至20天每日加2、第21天起每日加3，暂定上限80；全敌军每5天属性加5%，最高加100%。以下外征比例仅分配普通兵，不在人数公式外再加一批。

## 逐营表现

### 斥候营：首次击溃联军

轻帐篷与主帐，士兵疏松巡逻，射手在步兵后方。无墙、无塔、无常驻精锐，也不设固定攻城器械阵地。攻营重点是让恶霸接敌、猎手在后方输出，建立首次取胜与占领的反馈。

本营基础外征兵为步兵70%、射手30%，初始预备兵8步兵加4射手。第5天强力大考由真实外征编制补入重锤巨兵，不挪走先锋营的驻营巨兵。后期若玩家仍未推进，采用全局时间要求的更高阶外征编制，不永远只派步兵。

### 先锋营：靠阵容反冲，不靠城防

扩大营帐群，仍无围墙、营门、箭塔或固定攻击设施。普通步兵接战，射手压后，矮人和重锤巨兵守主营附近，跃墙兵快速反冲，追击受守备范围约束，不跑回玩家洞穴。

基础外征兵为步兵40%、射手30%、跃墙兵20%、矮人10%，预备兵为8/6/4/2。夜袭精锐候选是重锤巨兵和重枪突击手；候选不代表每波固定赠送，须符合强力预算和实际兵源。通过快攻与重击给低墙、防线后排施压。

### 前军营：首次完整攻坚

一层加固木围墙、一个营门、两座木箭塔，营内仍是普通帐篷和主营。两名塔射手计入14名精灵射手，圣盾重卫保护主营前的重装阵线，精锐长弓卫在后方输出。大盾与矮人负责守门，少量跃墙兵反冲。

基础外征兵为大盾40%、射手25%、矮人20%、跃墙兵15%。预备兵12大盾、8射手、6矮人、4跃墙兵。精锐候选为圣盾重卫、精锐长弓卫、重锤巨兵。

初始外征器械库一辆冲车、一辆投石车，每波最多调一辆。停在器械区的未调器械可参与本营防守；派出去后营内对应车位为空，缴获后不在两处同时保留。鼓励玩家用缴获器械攻塔破门，但保留足够军队直接攻坚的可能，不能做无器械绝对无敌的门。

### 中军大营：重装与火力构成纵深

两层错开防线，外层加固木墙、内层砖石营门，三座木石混合箭塔，后方为大型军帐和器械区。三名塔射手来自16名精灵，法师保持在后，攻城工头维修尚未被彻底摧毁的设施，不能复活已毁塔和大门。破城督军留守主营形成正面大考。

基础外征兵为大盾35%、法师25%、射手20%、矮人10%、跃墙兵10%。预备兵14大盾、10法师、8射手、4矮人、4跃墙兵。精锐候选为攻城工头、圣盾重卫、火焰大师；Boss候选破城督军和焚林导师，须使用独立外征个体，不派出驻营Boss。

初始外征器械库一辆投石车、一辆火焰投石车，每波最多调一辆。组织成前排盾阵、后排火力、器械推进，强力单位分布不同批次，避免一批全部送掉。

### 运兵船：短而集中的最终防线

与中军同属港口区域。码头入口一道木石与铁件加固防线，两座码头箭塔、两个船楼射击位，四名精灵射手正好分配到四处。船楼是射手高台，沿用箭塔交战规则，不新增跳台或登船操作。火焰大师提供范围压制，舰队统帅留守最终交战区。

基础外征兵为大盾30%、法师30%、矮人15%、跃墙兵15%、射手10%。预备兵6大盾、6法师、3矮人、3跃墙兵、2射手。精锐候选火焰大师、重枪突击手、圣盾重卫，Boss候选焚林导师。舰队统帅固定作为终局驻营Boss，不提前出现在玩家城墙前。

初始外征器械库一辆火焰投石车；每波最多两辆器械，第二辆只能来自真实后方库存或之后完成制造的新车，优先火焰投石车加普通投石车。没有库存只出一辆，不按上限凭空造第二辆。

守军30人不等于终局轻松：射击位更多，法术和固定精锐比例更高，交战区更集中。后续验收必须比较中军与船的实际破防和主力损耗，若终局偏弱，优先调整精锐占比、火力覆盖和站位，再讨论基础人数，不能仅凭纸面说明认定已经足够困难。

## 外征编制随时间的最低档位

守备保持各营特色，外征队采用当前前线与全局时间两者中较高的编制档位：第1至4天斥候型、第5至9天先锋型、第10至19天前军型、第20至29天中军型、第30天起港口型。玩家提前到高级营地会面对该营高级配置，久留早期营地也会面对后方调来的更强部队，人数始终不重置。

按当天人数先预留真实精锐/Boss名额，其余才按普通兵比例分配，以最大余数法取整到精确人数。真实库存不足时通过调拨与后续批次补足；若当晚确实无法补足就记录实际少派，不抽守备、不暗生人、不把一名长弓卫在两波中复用。

第5天强力大考保留，每5天增加一份强力预算，Boss占两份；预算只决定可用上限，候选表不强制全部出现。例如第21天前军型计划47人，可安排17大盾、11射手、9矮人、6跃墙兵，加1圣盾重卫、1精锐长弓卫、2重锤巨兵，合计47，不能又额外加4人。

## 器械库存与制造边界

以上器械库是新增提案，未纳入当前运行。器械与士兵分账，出征、撤退遗弃、缴获和摧毁都追踪同一ID；被缴获的同一辆车不会下晚原地刷新。攻城工头只能维修现存器械，不能免费生成新车。敌方制造器械的补充间隔与总量需与普通战役一起调校，本轮不声称旧代码已经符合此账本。

## 验收与状态

- 核算五营核心人数15/30/50/70/30、预备兵12/20/30/40/20、外征比例各100%、塔射手不超过本营射手；普通兵与精锐均使用现有稳定ID。
- 检查斥候、先锋零城防，从前军开始有墙塔，军帐始终为场景主体，固定射击位不免费造兵。
- 实施后检查同一时间/同等兵源下，攻下新营不会让外征编制降档；核心守军不被夜袭抽走，驻营Boss不会提前消耗。
- 实施后比较各营攻坚、五级防线承压、最终Boss战、库存不足时的恢复路径与真实手机性能。纸面人数与比例核对不代表玩法、成就感或性能已经通过。
