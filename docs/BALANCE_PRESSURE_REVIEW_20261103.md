# 战役持续压力反馈 2026年11月3日

用户新要求：压力应该随战役推进越来越大，不能只有前几天有压力。当前状态为已核对、已记录，尚未调校；本地42826固定包不因此改变。

## 当前运行安排

每日傍晚一次，由最靠前尚未攻下的营地出兵。袭击队与驻军预算独立。每波人数为阶段基础加本阶段经过天数乘日增量，再加本波强力实体数，受阶段人数上限限制。阶段基础6/9/13/17/22，日增2/3/3/4/4，上限18/24/32/40/48。强力实体包含在上限中，攻城器械另算。

斥候主要人类步兵、精灵射手；先锋加入普通跃墙兵和矮人；前军加入大盾；中军为大盾、跃墙兵、法师、精灵；运兵船为大盾、跃墙兵、较多法师、精灵和人类。第四天起波次每逢特定编制位置也会插入普通跃墙兵，故斥候阶段同样可能遇到。

第五天一份强力预算，此后每五天加一份；Boss占两份。第十天即可能出现破城督军，进入中军后改为焚林导师。六类普通精锐按全局天数和阶段循环。前军每波额外一辆冲车或投石车交替，中军和船每波一辆火焰投石车。

每批最多六名，每四秒补入。最多两支未撤退队伍同时推进，其余排队。编队倒地一半后撤，天亮不强退。
