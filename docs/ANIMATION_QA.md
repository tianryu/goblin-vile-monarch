# 动画关键帧与验收（用户新要求，优先于旧四帧方案）

旧4帧步态素材不合格，不能作为成品使用。用户指出联军步兵剑与盾在同一手中，已确认必须重做。

## 生成顺序
1. 先生成三张关键姿势：F0=左/近腿前接触，F4=右/远腿前接触，F8=F0闭合。对人类步兵，左手持盾在前，右手持剑在身体后侧向下，两手可辨且不共持。
2. 在F0/F4之间生成F2经过姿势，在F4/F8之间生成F6相反经过姿势；脚底/持物位置固定。
3. 再分别在F0/F2、F2/F4、F4/F6、F6/F8间生成F1、F3、F5、F7。形成8个有效帧；F8只作闭合参考，播放不重复。
4. 可将同阶段姿势放在一张等格候选图中生成，但必须实际执行关键帧→中间帧→细分中间帧三个阶段，不把一次生成的相似静态图当作完成。

## 必查项目
- 人物/坐骑身份、比例、衣服、工具、武器与颜色在整个周期保持一致。
- 步态近/远腿使用稳定明暗或鞋带区别，避免左右腿交换后视觉上仍是同一姿势。
- 接触、下沉、经过、抬升四个阶段可辨；不是几乎相同站姿、小幅位移或仅移动整张图片。
- 支撑脚的落点、身体/骑乘枢轴合理，避免抖动、滑步、头盔/工具闪烁。
- 首尾连续；闭合尾帧不重复播放，不以丢失中间姿势或复制静态帧伪造8帧。
- 剑盾分别由两手持握；弓、锤、锄、盾等握持关系逐帧检查，无多手、多脚、穿模、变形。
- 截图观察之外必须生成循环预览，检查正常速度和慢速循环。
- 自动比较仅作辅助：对齐后轮廓/腿部区域应有实质变化，躯干装备不可无故漂移；不能以文件哈希不同代表动作合格。
- 所有图片检查透明边缘、柔光污染、裁切、图格和实际游戏尺寸。发现问题重做，未经检查的候选图不覆盖成品素材。

## 范围
友方五职业、君主骑乘、四坐骑、联军三兵种，以及火焰/旗帜/特效逐项复核。静态建筑亦检查图层、透明度和比例。帧数按动作需要，不低于8个有效帧的主行走/奔跑/飞行周期。
