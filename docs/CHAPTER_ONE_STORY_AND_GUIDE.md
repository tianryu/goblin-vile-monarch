## 开场与第一次布防

君主身旁有1名拿木锤的苦工、1名拿弓的猎手和2名空手爪牙。赠送的工匠与苦工是同一职业。开场人口4，按现行一级主厅上限对应4/12，职业统计依次是2名爪牙、1名苦工、1名猎手、0名恶霸。图中参考截图的职业统计为占位，布局评审以人物和交互焦点为主。

开场显示「第1章 守住金币」。君主看向右边路口，在底部对话条里说：

> 人类军队就要来了，不能让他们抢走我的金币，我要在此处做好防守准备。

对白占用水面下部，场景中的四名下属和君主可见。用头像和发言人名字区分说话者，右下继续，右上跳过。开场阅读时暂停世界时钟，关掉对白就恢复操作。跳过对白后仍进入四步操作提示。

| 步骤 | 君主的提示 | 玩家做什么 | 何时推进 |
| --- | --- | --- | --- |
| 1/4 放置木锤 | 「那边有木锤。给空手的家伙一把，活就有人干了。」 | 用摇杆靠近木锤摊，按金币按钮，投足2枚。 | 一名爪牙领取木锤并成为苦工。 |
| 2/4 放置弓箭 | 「另一个给我拿弓。想碰我的钱箱，先吃一箭。」 | 到弓摊投足3枚，等空手爪牙领弓。 | 一名爪牙领弓成为猎手。 |
| 3/4 建造城墙 | 「在路口钉上木桩。让他们去撞木头。」 | 靠近城墙建造点，投足6枚。 | 苦工完成首道城墙。 |
| 4/4 建造箭塔 | 「让猎手站高些。谁往墙边走，就射谁。」 | 到箭塔建造点投足5枚。 | 箭塔建成，提示猎手可驻塔。 |

## 走到哪里与点哪里

每一步依次回答两个问题。远处先写具体去处，例如「向右走，去木锤摊」。地面虚线箭头从君主脚边指向目标，目标加金边和小名牌，摇杆相应方向轻亮。目标在屏幕外时，箭头指向对应屏幕边缘，随实际位置变向。

到达交互距离且当前对象确认为该目标后，收起路标，顶中提示改写具体按钮。右下对应按键加金环和点按手势，建筑或角色保留浅金边。若近处有多个对象且选中了其他目标，先提示切换目标，再高亮可执行按钮。移动目标的路标跟随角色位置。

木锤摊上方的两枚金币虚影对应两枚费用，按实际投币进度逐个点亮。付款完成后，手势收起，提示改成等待领工具或等待施工。开局赠送的职业不计为玩家完成的转职。走出交互范围后回到指路状态，所有标记用渐变衔接。

## 两个金币引导

**营地宝箱。** 君主「手下挣来的金币，大部分都放进了营地宝箱。钱袋不够了，就回去取。」

首次路过有存款的宝箱，或当前建设缺钱且宝箱有余额时，安排一次简短教学。离得远显示「回营地宝箱」和指路箭头。走到宝箱旁显示存量，并用手势指向右下宝箱按钮，提示「按右下角宝箱按钮取金币」。实际从箱中取出第一枚金币后收起教学。钱袋已满或宝箱为空时，待取币可用再出现点按提示。

**私藏金币。** 君主「这家伙藏了我的金币。过去给他一鞭子。」

首次看见真正持有私藏金币的哥布林时，标记那一名角色和他的腰包。路标随角色移动。玩家走到他身边并选中他之后，提示「按右下角鞭子按钮」，手势只指该角色对应的鞭打操作。成功抽出私藏金币后显示金币掉落并淡出引导。普通携带金币去宝箱的哥布林不触发这一条。每个存档只展示一次，记住已展示状态，后续其他角色私藏时不再弹出同一教学。

| --- | --- | --- |
| 第一波来袭 | 君主「火把到路口了。猎手上塔，墙破了就叫苦工去补！」 | 用日期表盘和敌人来向提醒夜袭，保留战斗操作。 |
| 第一晚守住 | 君主「金币还在。看看外头，他们丢下了什么。」 | 介绍掉落金币、缴获物和战后收拢。 |
| 首次出现可押送的俘虏 | 君主「活的关进牢里。牢门外那几个，盯紧点。」 | 引导拖运、监牢容量和笼外逃跑风险。 |
| 人类商人首次到营且玩家靠近 | 商人「这些人类、精灵和矮人奴隶，我都收购。你把人带来，我付金币。」君主「好。记得把你的车赶近点。」 | 高亮商人的交易按钮。玩家亲自成交后，商人装人离场。 |
| 初次布防完成后，首次有钱扩建主厅 | 君主「钱箱有了分量。把主厅扩一扩，叫更多哥布林来。」 | 给出主厅升级费用和可解锁内容。 |
| 主厅升到2级 | 君主「也许是时候主动出击，攻击敌方营地了。」 | 引导建造出征旗帜、集结再派兵，展示第一个可攻营地的方向。 |
| 攻下斥候营 | 君主「拿到了。把墙立起来，这条路才算归我。」 | 引导守住新领地。 |
| 首次可制作护甲 | 君主「把他们的铁甲改一改。猎手和恶霸都用得上。」 | 引导从缴获物到装备改造台，再到职业领甲。 |
| 首次遇到敌营箭塔和城防 | 君主「路口有塔。让前排牵住他们，给猎手留个好位置。」 | 提醒前线威胁与部队站位。 |
| 首次缴获攻城器械 | 君主「这东西撞过我的墙。修好它，下次去撞他们的。」 | 引导修械、两名苦力操作与编入出征队。 |
| 接近中军大营，首次与将军交锋 | 将军「你为什么要攻击我们？我们是去讨伐巨龙的。」君主「是你们先想要抢夺我的金币的。」将军「船上的人还在等我的军令。把路让开。」 | 在正式交战前短暂显示两方对白，然后恢复攻营操作。 |
| 攻下中军大营 | 君主「他们把船留在岸边了。跟我来，那艘船也归我。」 | 标明运兵船方向，延续最后一场战斗。 |
| 确认夺取运兵船 | 君主「也许我可以用这艘船去远征人类、精灵和矮人的领土，去抢夺更多金币。」 | 播放结尾对白，结算后显示「第二部敬请期待」。 |

## 新建筑和新变化的提示方式

招募盘、苦工和猎手以外的职业工具摊、生产设施、陷阱、修械设施及建筑升级，首次进入可用范围时各有一句与用途有关的台词。可立即操作时配目标高亮和费用图标。例句包括招募盘「摆上金币，无主哥布林闻着味就来了」，吊网「等它们挤过来，网就会兜住前排」。新敌人、新器械和新领地优先用短条提示，主线对白留给开场、第一次出征、中军交锋和结尾。

引导进度跟随真实的领工具、建成、交易与占领结果。已经完成的动作可以直接计入，金币不足时提示钱箱或可用收入来源。提示可收起，靠近相关目标可重新看到当下这一步。战斗中让次要提示排队，安全后接续。每条新内容只做一次首见引导，进度随存档保存。对话、金边、手势和提示条遵守项目的渐入渐出规范。
