# 成品整改与验收

2026年10月31日，用户明确否决当前整体效果，要求按可正式上架的完整项目整改，禁止将默认程序化按钮、窗口与文字外观作为成品交付。保持免费与自愿广告方案，本轮仍不生成角色帧动画。

本轮范围：独立生成窗口、按钮、资源栏、提示底板、横向摇杆、操作键、状态条与Logo，统一字体层级；四种坐骑使用完整骑乘组合贴图，包含失冠状态，校验座位、脚点、比例和朝向；重新组织HUD、窗口和商人商品展示；补齐开局指引、战斗压力反馈、出征与结算；按场景和实际流程检查，不以旧测试数量代替观感。

动态金额、价格、计时和任务描述仍由有许可的字体排版，并使用独立位图底板，不将动态数值写死在图片中。固定Logo及操作键图形用生成素材。后续UI不使用StyleBoxFlat、默认ProgressBar或draw_circle等绘制外观。

验收记录按每轮保留实际截图、发现的问题、修复和复查结果。横屏手机尺寸至少覆盖740x360、844x390、932x430和1280x720。所有按钮在安全区内可触达，弹窗必须有清晰关闭、主操作和可见价格，不能依赖长滚动查找核心选择。

玩法验收覆盖正常开局、招募分工、工具库存、建筑修复、真实私藏追缴、捕俘与监牢、商人交易、四种偷窃、无广告双向出征胜利、失败免费重开、存档备份、四坐骑和奖励异常。角色帧动画延后不影响以上规则和静态构图必须正确。

真实TapTap广告与真机需真实环境取证，不伪造SDK或硬件结果。平台应用由用户创建，本轮不操作平台发布。尚未完成全部验收时，不称为已达到上架成品标准。

## 已实施的整改

13种独立AI界面位图已经接入窗口、普通/主按钮、资源栏、提示纸、横向摇杆底座/旋钮、奔跑/交互/暂停键、进度框/填充和标题Logo。动态文字采用裁剪后的Noto Sans SC，窗口标题采用Ma Shan Zheng。两套字体均附SIL许可；运行界面不再使用默认矩形按钮、程序圆形摇杆或程序绘制血条。加载与错误重试界面复用同一组真实位图。

四种坐骑各有戴冠、失冠完整骑乘贴图，共8张静态图。人物坐在鞍座上，腿部、缰绳、坐骑一起变换；失冠图按原图边界导出，避免状态切换缩放跳变。世界与倒影调用同一绘制函数。角色帧动画仍未生成。

已修复：出征遗漏后排打手、工匠抢俘虏而忽视修复、俘虏搬运超订、盗贼误领其他职业工具、空地操作意外花钱、蝙蝠耗尽体力反复起落、地面近战仍能击中低飞首领、物资在盗贼抵达前消失、广告完成后返回键未恢复、损坏存档的解析报错和部分窗口底部裁切。箭台按等级分配站位，避免猎手全部堆叠；夜间人物明度与背景区分。营地有驻军，双向军旗需要实际搬回。

俘虏出售后进入商人的囚车，后笼、人物、前栏正确分层；单个工匠拖运，绳索连接网兜。商人保持中世纪套头短袍、露头造型。交易面板显示牢内和囚车人数。候补、金币储备、职业工具库存、两侧营地状态可以查看。

补充了9个短音效，共107804字节，来自Kenney的CC0音频，不是AI音频。覆盖操作、金币、确认、错误、战斗、牢门与脚步，附完整许可和来源：[Interface Sounds](https://kenney.nl/assets/interface-sounds)、[RPG Audio](https://kenney.nl/assets/rpg-audio)。受限的付费AI音频服务没有产生可用素材，也没有进行付费生成。
