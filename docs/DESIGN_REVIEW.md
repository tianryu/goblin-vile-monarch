# 功能基线设计复核记录

## 最新确认与三项纠错

用户认可平面手绘画风。当前修正商人现代夹克宽帽的时代错误、俘虏出现在前栏外侧的遮挡错误，以及拖运从两人改为单人。上一轮自检只核对了人数和阵营，没有正确识别笼前栏与人物的层次，属于漏检；新验收必须逐个检查四名俘虏全身处于框内、前栏确实遮挡人物，不能仅凭4/6标牌判合格。

商人改露头粗麻套头短袍与束腰带，取消马甲衬衣和宽帽；单人牵绳方向需与朝监牢移动一致，水面不得残留第二搬运者或旧帽。只认可画风，修正版局部与整组仍需审核，不生成正式素材。

## 最新美术修订 平面手绘方向

用户反馈上一轮四图3D/建模感偏重、细节和色彩分离过强。新方向减少亮暗体积、材质纹理与硬描边，改用更平的手绘大色块、低饱和与接近明度，保留低像素、小角色与关键轮廓。人类商人明确取消风衣，采用腰长短马甲、卷袖衬衣、布裤和软帽。

当前只做一张监牢交易方向稿供审核，art/design/reboot-v2-flat。上一轮构图可参考，美术风格未批准，不能以历史自检记录覆盖此次反馈。

## 第二遍：规则冲突与资产边界
- 修复满钱袋吞广告币：独立随身储备、自动补袋。
- 修复无限援军与手机性能冲突：现役上限仅限制模拟，超额持久待命，可补员/带入新征程，不限制领取。
- 修复反复解锁已拥有坐骑无收益：变为明确增加300秒强化。
- 修复强化在商店/广告/后台流逝：只计对应坐骑实际游玩时间。
- 修复换骑刷满体力：保持体力百分比。
- 修复失败清空未用广告奖励：全局资产和征程资产分开。
- 修复无限广告币架空金币坐骑购买路径：允许广告币用于购买，仍保留自然收入积攒，符合玩家自主外挂要求。
- 修复低飞绝对无敌与交易悬空：远程威胁/落地交互；广告强化仍允许长时间飞行，符合外挂定位。

## 第三遍：流程可达性、异常与12小时可做性
- 新手：招募→工具→墙→第一夜；商人可选不强制；常规收入支持正循环。
- 中期：农具/菌田→大厅升级→队长与小队→左右出征→反击→胜利；免费失败可重新开始。
- 广告：先选收益→暂停→播放→有效回调幂等保存→显示到账→关闭商店恢复；无库存/提前关无损返回。
- 手机：多指、手势取消、安全区、横竖屏、后台帧时间、字体与像素场景分别处理。
- 存档：重载、损坏、禁存储、首次领取后崩溃及新征程边界已列门槛。
- 缩减：单图、单人、固定建筑位、四坐骑、三商人；删除多岛、联机、声望、云存档，保留完整胜负。
- 广告未开通是外部前置条件，不用旧应用ID，不承诺模拟验证替代真实播放。
