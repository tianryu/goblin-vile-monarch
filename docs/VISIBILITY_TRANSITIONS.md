# 显隐、落地与人物可读性修订

2026年10月31日。当前规则优先于V7早期禁止全部说明文字、固定脚点和插地价格牌的旧设计。仍只保留胜败结算窗口，不生成角色帧动画，不操作TapTap应用。

## 当前实现

- 所有显隐复用透明度过渡，常规出现180毫秒、消失220毫秒，短战斗特效缩短到45/100毫秒。覆盖金币虚影、建筑虚影、未建木牌、目标光边、按钮、两行建筑说明、结算、人物/物件、库存、掉落、金币堆、天空元素和启动幕。快速折返从当前透明度继续。
- 视觉缓存只保留绘制快照，不参与规则、随机与存档。离开目标立即使旧交互失效并按原规则退款，旧图继续淡出。暂停时界面过渡仍完成。重开先淡入遮罩，完全覆盖后重建，再淡出；没有新增确认窗口。
- 接近建筑时，上方以原AI深色底板显示大字名称与小字简短作用。没有教程或商店弹窗。重复的插地价格牌退出渲染；未建造位置的木牌、商品本身和费用金币虚影保留。
- 地面从原AI贴图连续不透明区采样，建筑、角色和树根按该高度放置，补接触阴影与少量原草边遮挡。地面贴图与世界坐标对齐。金币堆修正为下宽上窄，底排落地。
- 所有阵营人物和人类商人使用实时清晰描边。原人物主体alpha中位约253/255，融合感主要来自色值与轮廓；新着色器让主体实心，保留边缘抗锯齿、正常显隐和水中倒影透明度。夜间给人物保留可辨识亮度，不改变建筑的月光/火光。
- 当前交互目标使用约3个世界像素的金色宽光边，亮度提高，继续呼吸和渐入渐出。光边、火炬光、脚点与新地面高度对齐，不留偏位重影。
- HUD钱袋复用原位图，袋身透明、袋口较清楚。每枚携带金币都有独立显示身份，错落落入并轻微回弹，位置和角度不整齐；花费移除相应金币。纯视觉随机源独立，不额外产生收益。
