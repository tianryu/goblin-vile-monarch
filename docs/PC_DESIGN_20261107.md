# PC 版设计与中英文支持

更新日期：2026年11月7日

## 版本边界

公开仓库：https://github.com/tianryu/goblin-vile-monarch

`main` 保存当前手机 TapTap 小游戏基线，首个提交为 `49e1bc4`。`codex/pc-desktop` 是独立 PC 改造分支，继续使用 Cocos Creator 3.8.8、现有手绘美术和第一章战役。主要交付目标是 Windows x64 原生程序，桌面浏览器包用于快捷试玩与界面验收。

本轮不改战役难度和兵种数值，不扩第二章，不接 Steam 服务。手机版存档和旧构建保留。手机转向掉帧反馈仍需原设备复测，PC 结果不能替代。

## 操作与布局

| 输入 | 行为 |
| --- | --- |
| A、D 或左右方向键 | 水平移动 |
| 按住 Shift | 奔跑，耗尽体力后松开才可再次触发 |
| E 或空格 | 当前目标的主要交互，按住连续投币或取币 |
| Q | 抽鞭，位置固定，不与投币互换 |
| R | 当前目标的第二项操作，例如升级 |
| Tab | 在附近交互目标中切换 |
| H | 快速回洞，沿用既有冷却与条件 |
| M | 打开或关闭坐骑选择 |
| Esc | 暂停或恢复；对白时跳过当前对白 |
| Enter | 继续对白 |

移除 PC 的触屏摇杆和大尺寸手机动作区。底部中央展示固定的 E、Q、Tab、H、M 操作图标及键位，R 按条件补充。左下角为移动提示和体力条，右上角为暂停。保留场景靠近交互、金币虚影和目标描边，不添加点击远处建筑直接执行的规则。

主菜单、暂停菜单保留吊牌风格与离屏后恢复世界的动画。移除 PC 未接通的排行榜、云存档及广告入口，保留继续、新征程、语言、声音、主菜单、鸣谢等实际可用项。新征程覆盖存档前需确认。Windows 初始客户区为1280x720，桌面预览自动填充窗口，不带引擎测试页的页眉与页脚。

失焦时释放所有按键并暂停，返回时不保留移动或投币。退出窗口前保存。所有显隐继续采用既有渐入渐出。

## PC 坐骑与死亡

PC 界面不提供激励广告。保留普通死亡后的整顿部落、半数设施与居民损失、金币清空和停袭一天规则。

坐骑改为一次性金币解锁：野猪初始拥有，巨蜥30、疾风狼40、巨蝠50。价格集中在 `DesktopRules.ts`。已解锁坐骑免费切换；支付失败不扣费，重复选择不再次收费。此定价是本轮 PC 初始设计，后续可按试玩反馈调节。

## 中英文国际化

中文名称《哥布林：卑劣君主》，英文工作名称 **Goblin: Vile Monarch**。英文标题使用单独生成的透明艺术字素材，与原中文标题分别存放。

语言支持简体中文和英语。主菜单和暂停菜单各有语言项，点击立即切换。不重新加载战役，不改变随机数、资源、单位、战斗状态、引导完成记录或剧情进度。声音与语言保存在独立设置，重新开局不重置。PC 使用独立存档命名空间 `goblin-vile-monarch-pc-v1`，不自动覆盖或导入手机版存档。

翻译覆盖菜单、剧情、引导、建筑和职业名称、建筑作用、战鼓状态、动态金币与人口、死亡与通关、鸣谢。稳定 ID 与规则不翻译。显示入口为 `Painter.text`，长段对白先翻译后按英文单词换行。限制宽度的短文本允许缩小适配；保留现有字体和大字可读性。

英文词条集中在 `i18n/en.ts`，模板与语言状态在 `i18n/Locale.ts`。缺失译文记录到开发检查集合，正式业务不依赖译文。后续新增文案必须同时维护两种语言。

## 实施步骤与验收

| 步骤 | 验收标准 |
| --- | --- |
| 保存手机基线 | 公开仓库 main 可访问，远端 SHA 与本地基线一致，排除缓存、输出和凭据 |
| PC 输入与界面 | 键盘移动和按住投币可用，E/Q 固定，Tab 切换，失焦不粘键，无手机摇杆与广告 |
| 本地化 | 两种语言可从正常菜单切换并持久化，五段剧情可翻译，切换不改战役，动态数值与主要界面无残留中文 |
| 桌面原生构建 | 生成 Windows x64 可执行文件，资源随包完整，启动进入正常菜单，能开始并移动、暂停与切换语言 |
| Git 交付 | PC 源码、素材、构建配置和说明提交到 PC 分支，远端分支一致，交付包与证据位于本地输出目录 |

本轮实际执行结果见 `PC_DELIVERY_20261107.md`。本设计与旧手机文档冲突时，仅在 PC 分支以本设计为准。
