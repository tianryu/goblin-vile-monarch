# 夜袭只按天数的口径纠正

2026年11月3日。用户明确纠正：夜袭难度提升只看天数，无论推进到哪个营地，日期到了，相应强力单位与工程器械都必须出现。此前按营地指定夜袭类型、取营地与日期较高档位、让初始外征库存限制后期出兵的表述全部废止。此轮是方案修订，不修改42826固定包或运行代码。

## 时间威胁日程，具体日期为本轮提案

- 第1至4天：步兵与精灵射手，无器械。
- 第5天起：加入普通跃墙兵，首个重锤巨兵大考，不借用先锋驻营巨兵。
- 第10天起：大盾、矮人重装比例增加，出现冲车，精锐候选扩展到长弓、圣盾与重枪。
- 第15天起：普通投石车加入，外征精锐中可有攻城工头。
- 第20天起：法师成为常规兵种，火焰投石车与破城督军进入夜袭日程。
- 第25天起：夜袭Boss可出现焚林导师，Boss种类轮换仅看日期，不看营地。
- 第30天起：大盾与法师占比进一步提高，编制为一辆火焰投石车和一辆普通投石车。

第五天起强力预算仍为floor(day/5)，Boss消耗两份。舰队统帅是运兵船驻营Boss，不夜袭；普通强力同名职业可有独立外征个体，不能复用驻营ID。精锐/器械日期必须兑现，不能因低阶段营地而禁用。补员和制造需在日程之前调度，不在失败后复活同一批士兵或把缴获车复制回去。

详细日期配比以data/global-raid-calendar-proposal.json为唯一提案来源，字段只接收globalDay，禁止加入campIndex、capturedCampCount或hallLevel等提档条件。所有敌军属性每5天在基础值上增加5%，最高增加100%，与进度无关。

## 补员与伤亡的取舍

为兑现用户要求的时间压力，旧的每日35%外征补员硬上限与库存不足就常态少派的设想废止。外征新兵与器械根据下一晚的编制缺额和在途需求提前安排，新增个体记入真实补员/制造账，夜袭损失仍在首次倒地时扣原个体，撤回、缴获和出售不重复结算。核心守备不用于填夜袭缺口。

这意味着守城主要获得本夜安全、俘虏、金币、装备、缴获器械与整备时间；不再把长期守城可磨空后续夜袭作为承诺。玩家攻营会影响发兵地点、运输路线、剩余守备和占领，但不作为降低当晚难度编制的条件。实际运输和制造参数尚需实施调校，不能声称旧35%比例仍能保障这张新日程。

## 用户补充的设施和终局布局

后期营地可以有多道纵深围墙和两至三层箭塔。初拟中军三道防线，三座塔的平台层数3/2/2，7名塔射手从16名精灵守军中抽取；船码头与登船口两道防线，四处双层射击位共8名射手，从30名核心守军内重新分配，不能免费增加人数。斥候与先锋仍只有士兵、帐篷，无墙无塔。

中军与运兵船必须紧挨，营区后面直接衔接码头，不安排长野外段。修订布局初拟中军中心26500、宽2400，船中心28500、宽1400，两者之间仅100单位码头连接，替换先前中心间距3000的方案。地图整体加长放在前面三个大段野外，不把最终两营拉开。

守备15/30/50/70/30指留守核心编制，不参加夜袭，所以不因夜袭折损；被玩家主动攻营击倒、杀死、俘虏时会真实减员，不是无敌、不死或每次访问自动回满。

## 验收口径
