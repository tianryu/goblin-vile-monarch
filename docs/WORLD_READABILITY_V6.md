# 世界识别与首领生存V6

本轮功能与正式Web导出已实现，以下为当前执行规格。旧V5验收数字不能自动沿用。

用户最新要求：未建造位置使用插地木牌，靠近后木牌切换为目标建筑虚影；未投满金币离开后返还；四职业分别有高辨识度工具摊；容易被骑乘角色挡住的建筑抬高；战场遗物重做为确实落地的破损车队残骸；移除偷王冠玩法，改为击杀哥布林首领。

执行规格：

- 木牌使用独立AI透明位图，只有实际尚未建造的大厅外设施显示。唯一当前目标用建筑虚影替换木牌，施工中继续使用施工虚影，不能叠着木牌。离开后恢复木牌。
- 投币、靠近提示和退款使用同一72单位边界。未完成的钱按普通袋内金币、广告袋内金币和储备来源全额归还，并提示数量。退款允许钱袋临时超过50枚，防止退款时被新收入挤掉；普通收入仍受携带上限约束。完成施工备料后的费用不退。
- 工匠、猎手、打手、盗贼各有独立摊位、外观、标志和购买面板。工具购买后挂在对应摊位，空闲爪牙实际走到该职业工具摊领取，库存和职业不能串。
- 部落街道为新增摊位拉开间距，防线和林地据点随之错开。升级状态、人口、库存、金币、任务ID和已获奖励在旧存档迁移时保留，补齐新摊位，避免密集重叠。
- 重要建筑高度超过骑乘首领：大厅、工具摊、广告商人、盗贼窝、监牢、联军营帐均有可见高部轮廓。箭台驻守高度、建设虚影、施工条和投币槽同步调整。道路和所有底座保持落地。
- 战场遗物使用独立的倒塌车厢、断轮、碎木、旧盾和倒旗整体位图，车底由断轴、轮子及碎石支撑，取消去掉轮子后悬空的完好车身。
- 首领初始100生命，联军攻击扣生命，金币不挡伤害，不掉落、抢夺或携带王冠。王冠只保留在首领形象上作为装饰。生命耗尽才判负；大厅被摧毁不直接判负，改为破损废墟、停止疗伤，敌军继续追击首领，大厅可修复。
- 首领在白天回到安全且完好的大厅附近，每秒恢复8点生命。失败仍免费重开，不加广告复活。旧版本掉冠状态迁移为正常首领，旧版因王冠或大厅失败的存档可按新生命规则继续，已经获胜的征程保持获胜。
- 所有新建筑、标牌、残骸、心形图标均独立AI生成静态图，逐一检查后才进入生产。角色帧动画仍延后。本轮不增加程序代画素材或新程序特效。
- 透明环境层按有效区域裁切，同时保留原始布局偏移，减少空透明像素驻留，为新增独立建筑腾出内存。画面构图不得因此跳位。

验收：逐枚退款和资金对账；四摊入口及真实领取；旧存档无重复摊位迁移；木牌/虚影互斥与边界；首领受伤、恢复、死亡、免费重开；大厅废墟与修复；不同建筑高度、箭台、囚笼与残骸接地；桌面H5真实触控回放及正式包启动。真机、真实广告与平台发布保持未验证，不使用旧版数字冒充。

## 已完成的功能验收

当前模型回归43项、整改场景35项、投币成长32项、本轮世界与首领36项、原生UI5项通过。V6浏览器触控33项、全页面与保存广告适配器回归54项、正式包9项、启动错误页与音频解码9项通过，共256项本地场景断言。广告回调使用明确的测试适配器，不能称为真实TapTap广告测试。

测试覆盖普通钱袋、广告钱袋、储备混合托管、边界退款、满袋退款不吞钱、退款幂等、四摊单独购买与真实走近领取、旧存档迁移与重复加载、首领扣血、受击保护、疗伤、安全条件、大厅废墟维修、首领死亡、同时死亡与运旗的判定、免费重开。浏览器使用844x390与DPR2，并注入左右24和底部34 CSS像素安全区，另检查740x360与960x480页面边界。

完整征程测试暴露并修复两个连带问题：猎手在黎明时忽略未清除的敌军；掉在远处的军旗超出工匠原先的搜集半径。现在对应侧仍有入侵者时继续守线，目标军旗允许安全地远距离回收。扩大地图后，俘虏搜集也不再被原来的1400半径挡住，工匠会选择安全且来得及赶到的活口。采用修防线、预留守军、分次出征和回营疗伤的普通测试策略，种子731、123、55均在第5日取得双旗，没有广告或资源注入。征程为加速模型测试，不是手机实玩时长证明。

## 美术与内存文件预算

十二张新生产素材均由内置image_gen独立生成，提示词、原始路径、检查意见在[素材源目录](../game/art/source/world-v6)。三张细节过密候选保留于该目录的rejected，盗贼窝、残骸与废墟已重新生成，采用更平面的哑光色块。全部为静态透明位图，未生成角色帧动画。

运行共111个部件、34张纹理，单份RGBA为18790944字节，约17.92MiB。环境四层只裁去透明行，保存原始竖向偏移，净节省4995840字节；新增建筑统一图集后，较V5仍少2636544字节。启动副本、运行素材和128像素开场图保守合计21507600字节，约20.51MiB，低于24MiB文件预算。这不是手机进程或GPU总占用。

实际运行图集中在[本轮对照页](../art/design/world-v6/index.html)，这里的24张图是实际截图，不是独立目标设计稿，也不伪造90%相似度。画面已逐项查看接地、木牌与虚影互斥、建筑高位标识、囚笼前后层、箭台驻守、UI安全区和骑乘锚点。

正式预览为http://127.0.0.1:42820/，需要刷新加载新导出。没有创建、修改、上传或发布TapTap应用。手机、宿主与真实广告SDK仍待实际环境验收；帧动画按用户要求继续延后。完整当轮记录见qa/godot/v6-acceptance.json。
