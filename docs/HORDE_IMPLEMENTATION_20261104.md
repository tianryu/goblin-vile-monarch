## 性能处理

- 活敌表及ID索引按逻辑状态失效缓存，不让每个单位每次范围判断都分配完整过滤数组。
- 最近目标采用线性扫描；敌方可攻击目标每步装配一次；哥布林目标保持和寻敌降频减少反复决策。
- 危险区列表每步只生成一次，塔位和层高每步缓存；局部有效兵力按160区段、250毫秒缓存。
- 接敌队列保持次序，避免每帧重排造成前后互换；前排有限接敌，后排真实补位，不堆在同一点攻击。
- Painter缓存UITransform/UIOpacity，避免重复组件查询，图片、颜色、尺寸、锚点和层序相同则不重复设置。
- 晨暮色调每画面计算一次，复用颜色对象；护甲只用两份共享材质，复用现有正持斧AI贴图和关节，没有新增动画图集或人物贴图。
- 保留原有视野裁剪、离屏AI降频、真实驻军与外征补入队列、贴图加载限流和按需交互光边。

本批未运行帧率、内存或手机测试，不提供新性能数值，不继承旧桌面约30帧或纹理119至136MiB的结论。没有根据源码优化预先声称手机达标。
