## 已明确的制作方向

用户要求后续动画不再用序列帧，改成贴纸般一顿一顿、带抽帧感的动作。可描述为贴纸式剪纸动画，结合有限动画与关键姿态停顿；这些词分别描述造型、动作量与节奏，没有必要锁定一个唯一名称。

后续不重启旧H3序列帧队列，不继续生成视频抽帧或新动作图集。现有已采用序列帧是历史版本，先保留，不在讨论阶段擅自删除或替换。当前尚未授权动效原型实施，不生成新素材或动画。

## 运动方案建议

- 使用原有或独立生成的少量静态位图，整体纸片或按需要分成头、躯干、手脚、武器。运行时以位置、转角和少量缩放形成姿态，不用一张张完整重画角色。
- 关键姿态短暂停住，再明确切到下个姿态，形成有意的抽格节奏。具体采样频率待样例确认，不把整款游戏渲染帧率降低来模拟风格。
- 移动坐标、镜头与输入保持平滑；脚点和坐骑鞍座保持稳定，不用全身正弦上下跳代替走路。
- 受击可用绷直、后仰、抖两下、回位，攻击有预备停顿和出手重拍；业务伤害只在真实攻击事件结算一次。
- 建筑、交互场景、旗帜、树木和装饰采用同一剪纸语言，摆动幅度和节奏按层次减弱。树根、建筑基础固定，旗布/树梢等局部运动，避免每栋建筑整体摇晃和所有树同步抽动。
- 用户此前明确保留的程序化火焰、水流和天空移动不改回序列帧；是否也加入停顿采样属于后续样例讨论，不先强制所有效果一起顿挫。
- 全局出现/消失仍渐入渐出。姿态的阶梯变化与透明度显隐分开，不能因定格感让按钮、金币槽或建筑虚影突然闪现。
- 拆分部件可能增加绘制和轮廓处理成本。低内存、低硬件目标仍需实际原型测量，不把新风格直接当成已经更省内存的证据。

## 描边分层

用户已要求试样：己方白色宽边、敌方淡粉宽边，并询问场景描边。下列是当前效果稿方向，具体粗细、颜色和运行表现待确认。

| 对象 | 当前效果稿与建议 |
| --- | --- |
| 己方角色及骑乘整体 | 清晰白色宽外边，保留原深色内边和不透明主体 |
| 活跃敌军 | 淡粉色宽外边，与己方相同层级 |
| 未选中的可交互建筑 | 清楚可见的浅米色实线外边，沿真实轮廓，不是矩形框 |
| 选中建筑 | 金色呼吸选择边，保持建筑识别；人物挡在前面时不得透过人物 |
| 前景树木、草叶与装饰 | 较弱的深蓝绿或顺色暗边，不套白色大光圈 |
| 中远景 | 逐渐降低边缘对比，远景柔和，不争夺角色注意力 |
| 金币、特效与UI | 延续各自既有规则，不因场景描边给所有文字/按钮/水面统一加外框 |
