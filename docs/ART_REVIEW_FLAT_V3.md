# 统一手绘美术检查

用户最新决定：整款游戏统一采用本轮新生成的非像素平面手绘卡通风格。此前像素方向停止使用，用户点名的像素人类士兵必须替换。保留中世纪背景、丑萌狡猾哥布林、分层环境与静态贴图范围。

当前源目录：game/art/source/flat-v3。基准为worker、hunter、monarch、trader，以及重新生成的human。正式资源只由scripts/prepare_godot_assets.py从选定源图裁切、缩小和打包；没有程序替代角色、建筑、道具、地形或特效。水面倒影只是同一位图的翻转和透明度变化。

## 审阅与视觉指标

用户采用的是这套新风格方向，不等于每张源图都经过用户逐项确认。当前素材已经人工自检并接入Godot，查看art/design/flat-v3/index.html。页面中的运行检查图来自浏览器内的真实Godot渲染，使用测试布置，不冒充自然通关画面。

历史像素设计图只保留布局参考。90%视觉相似度要求仍保留，但当前风格已由用户主动改变，需要新版同视角目标图作为有效对照；没有把旧图直接换成实机自身来刷相似度，也没有宣称已达到90%。该指标尚未判定通过。
